📌 BƯỚC 1: Khởi tạo CodeGraph (Chỉ cần 1 lệnh)
Mở Terminal (PowerShell / Command Prompt / Terminal trong VS Code) tại thư mục của dự án mới và chạy lệnh:

bash
codegraph init
👉 Lệnh này sẽ tự động:

Quét toàn bộ mã nguồn của dự án (.ts, .tsx, .js, .py, .java, .cpp...).
Phân tích cú pháp (AST) để xây dựng biểu đồ mối quan hệ giữa các hàm, class, interface và file.
Tạo ra thư mục .codegraph/ trong dự án để lưu cơ sở dữ liệu chỉ mục (index).
📌 BƯỚC 2: Thêm .codegraph/ vào .gitignore (Khuyên dùng)
Do dữ liệu index được sinh ra cục bộ trên máy bạn, bạn nên thêm dòng sau vào file .gitignore của dự án để tránh commit file này lên Git:

gitignore
# CodeGraph Database local
.codegraph/
📌 BƯỚC 3: Quy trình dùng hàng ngày trong dự án mới
Sau khi đã init, trong quá trình lập trình bạn chỉ cần nhớ 2 lệnh cơ bản:

Thao tác	Lệnh chạy	Tác dụng
Khi vừa sửa/thêm code mới	codegraph sync	Cập nhật nhanh chỉ mục cho các file vừa thay đổi
Kiểm tra trạng thái index	codegraph status	Xem tổng số hàm, class, file đã được index
Tạo lại index toàn bộ từ đầu	codegraph index	Chạy lại index sạch nếu có thay đổi cấu trúc lớn
💡 MẸO BỔ SUNG:
Nếu là dự án Node.js / React / Next.js: Bạn có thể thêm vào phần "scripts" trong package.json để chạy bằng npm:
json
"scripts": {
  "codegraph:status": "codegraph status",
  "codegraph:sync": "codegraph sync"
}
Tích hợp với các Trợ lý AI / IDE (Cursor, Claude Code, Codex...):
bash
codegraph install
(Lệnh này giúp AI trong trình biên dịch tự động đọc và truy vấn CodeGraph khi làm việc với dự án của bạn).
